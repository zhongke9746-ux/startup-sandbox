======================================================
  创业沙盒 · 使用说明
======================================================

这是一个「先看环境、再做决策、最后结算」的创业模拟器。
你填一个项目和一笔钱，它在冻结的行业环境里按月推进，
在关键节点把选择权交回给你，跑完给你一份可行性评估。


一、怎么打开
------------------------------------------------------

Mac：
  1. 双击「启动-macOS.command」
  2. 浏览器会自动打开一个本地页面
  3. 用的时候别关那个黑色终端窗口，关了服务就停

  如果双击提示「无法打开，因为无法验证开发者」：
    · 右键点它 → 选「打开」→ 再点「打开」；
    · 或者打开「终端」，把下面这条粘进去回车（把路径换成实际路径）：
        chmod +x "启动-macOS.command"

Windows：
  1. 双击「启动-Windows.bat」
  2. 浏览器会自动打开
  3. 同理，黑色窗口别关

  如果双击后窗口闪一下就没了，或者提示 Python 3 was not found：
  就是这台电脑还没装 Python。去 https://www.python.org/downloads/
  下载安装，第一屏一定要勾选 "Add python.exe to PATH"，
  装完再双击一次（装一次，以后都不用管）。

  如果双击后弹出的是应用商店：那是 Windows 自带的「假 Python」占位符，
  去 python.org 装真的一次就好。

  实在不想装 Python 也没关系——找发你这个包的人要在线链接，
  那个是点开就能用的，什么都不用装。

  如果双击没反应、或者提示「Windows 已保护你的电脑」：
  右键点 启动-Windows.bat →「属性」→ 勾选底部的「解除锁定」→ 确定，再双击。
  （这是压缩包从网上下载后带的标记，不是文件有问题。）


二、需要装什么
------------------------------------------------------

只要求电脑上有 Python 3（3.7 以上）。
· Mac 一般自带，或者装一次 python.org 的官方包
· Windows 通常没有，去 https://www.python.org/downloads/ 装，
  安装时务必勾选「Add Python to PATH」

除此之外不需要装任何东西：不联网、不装依赖、不注册账号。
所有数据都存在本机的 sessions 文件夹里。


三、页面上怎么玩
------------------------------------------------------

1) 开局表单
   地点、行业、具体业态、资金、面积、员工数、客源方式、
   是否加盟、模拟月数、是否已开业。
   能填多细填多细——房租、客单价这些直接决定结论是准还是糊。

   表单里还有一栏「模型 API」：
   填一个 DeepSeek 的 Key，点「开始这一局」时会先联网抓这个地点、这个行业的
   公开信息（租金行情、监管政策、价格战、地方补贴），抓完当场告诉你抓到几条来源、
   几个事件、哪些数字被压回机理边界。一次约 ¥0.04。
   Key 只在本机这一次请求里用，不会写进会话，也不上传。
   留空也能玩，用的是包里已经冻结好的快照——区别是：填了，世界对得上你所在城市
   此刻的现实；不填，世界是别人抓的那个时间点的版本。

2) 跑起来
   每到一个决策点，页面会给你 3–5 个可选动作（提价、加人、开渠道、
   收缩产能、融资……），每个都标了：大概成功率、能不能撤回、
   要不要一次性花钱、以及这个动作在你这行的实际含义。
   你可以选一个、选多个，也可以什么都不做直接过——「不做」本身
   也是决策，账本会记住。

3) 看账本
   页面底部是现金曲线和逐月明细，营收/成本/净现金一眼能看到。

4) 跑完拿结论
   点「生成评估」大约等 30–60 秒（它在后台跑几百条路径，
   算存活率、中位数、最差 5% 情形），然后给你：
     · 这家活下来的概率
     · 终局现金的中位值和悲观值
     · 当前盈利率、保本点
     · 哪几个动作真的赚到了钱（动作归因审计）
     · 风险点清单
   再点「审计」可以看到每个决策单独值多少钱。


四、几点要提前知道（避免误会）
------------------------------------------------------

· 环境是「快照」，不是实时联网。
  行业价格、租金、政策这些外部信息是在某个时间点冻结进去的，
  之后不会自己更新。快照的截止日期在开局页能看到。
  想更新，需要重新抓一次再生成新快照（开发者动作）。

· 只支持已经做了行业原型的品类：咖啡店、健身房、中式简餐。
  选别的行业会落到最接近的原型上，结论精度会下降。

· 它是个「决策陪练」，不是预言机。
  结果的意义不在于预测你会赚多少，而在于：
  在同样的环境下，哪个选择把结果推高了多少、哪个把结果拖垮了。
  所以「什么都不做」这条基线一定要跑一次做对比。

· 数字会随随机种子变。同一个项目换个种子重跑，结论方向应该
  稳定，具体数值会有出入——这本身就是信息：如果你的结论经不起
  换种子，说明它本来就在临界点上。


五、数据在哪
------------------------------------------------------

sessions/ 文件夹里，一个会话一个 json。
想备份就整个文件夹拷走；想分享某一次模拟，把对应的 json
发给对方，对方放进自己的 sessions/ 就能打开。
想重开就删掉其中的文件（不会影响程序本身）。


六、想改点什么
------------------------------------------------------

rules/     规则库（机理、动作、适用性、概率分布），yaml 明文，
           改完需要重新编译成 build/*.json 才生效
build/     编译好的规则，程序实际读的是这个
snapshots/ 环境快照，一个行业一个文件
scripts/   引擎与会话逻辑
web/       前端页面，单个 html 文件

改造前建议先跑一次 scripts/verify_session.py，
确认你的改动没有让历史会话无法重放。
